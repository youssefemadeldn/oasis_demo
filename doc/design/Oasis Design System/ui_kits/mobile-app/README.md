# Mobile App UI Kit

Click-through recreation of the Oasis policyholder mobile companion app.

Flow: Login → Home (dashboard) → Policies list → Policy Detail → Claims list → Claim Detail (status timeline) → Submit Claim (form + confirm sheet) → Profile (settings).

Built entirely from `components/core`, `components/forms`, `components/navigation` primitives — no new visual patterns introduced. Mock data lives in `mockData.js`.

Open `index.html` to try it.
