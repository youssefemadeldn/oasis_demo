Clickable action button in five variants (primary/secondary/ghost/danger/dark), used across app CTAs and dashboard toolbars.

```jsx
<Button variant="primary" size="md" onClick={submit}>Submit Claim</Button>
```

Variants: `primary` (solid brand blue, glow shadow), `secondary` (white with border), `ghost` (text-only), `danger` (red, destructive), `dark` (navy, for dark surfaces). Sizes: sm/md/lg. Supports `icon`, `disabled`, `full` (100% width, common in mobile CTAs).
